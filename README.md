# أكاديمية السباحة

تطبيق ويب متجاوب (Responsive PWA) يعمل على الكمبيوتر والموبايل، لإدارة أكاديمية سباحة:
الطلاب، المدربون، الكلاسات والحصص، الحضور والغياب، التقييمات والمهارات، الاشتراكات والمدفوعات، والإشعارات.

## الهيكل

```
server/   API بـ Node.js + Express + SQLite (node:sqlite)
web/      واجهة React + Vite (طالب / مدرب / أدمن)
```

## المتطلبات

- Node.js 22.13 أو أحدث (يستخدم `node:sqlite`)

## التشغيل محلياً

```bash
# 1) الخادم
cd server
npm install
ADMIN_EMAIL=owner@academy.local ADMIN_PASSWORD='change-me-123' npm run dev   # http://localhost:4000

# 2) الواجهة (في terminal آخر)
cd web
npm install
npm run dev                                                                  # http://localhost:5173
```

عند أول تشغيل يتم إنشاء: المستويات الأساسية، رياضة "سباحة" مع أول مهارات، وحساب الأدمن من متغيرات البيئة (لو مفيش أدمن موجود).

## الإنتاج

```bash
cd web && npm run build           # يبني web/dist
cd ../server
NODE_ENV=production JWT_SECRET='...' PAYMENT_WEBHOOK_SECRET='...' DB_FILE=/data/academy.db npm start
```

- السيرفر يقدّم واجهة `web/dist` ويكون الـ API تحت `/api` على نفس البورت.
- `JWT_SECRET` إلزامي في production.
- النسخ الاحتياطي: `npm run backup` (يكتب نسخة متسقة من قاعدة البيانات في `server/backups` ويحتفظ بآخر 14 نسخة).

## الاختبارات

```bash
cd server && npm test     # اختبارات تكامل للـ API (تسجيل، صلاحيات، حضور، دفع، ترقية)
cd web && npm run build   # تأكد إن الواجهة بتتبني
```

## الأمان والتشغيل

- كلمات المرور: `scrypt` مع salt. التوكن: HMAC موقّع مع مدة انتهاء 12 ساعة، والمستخدم بيتعاد التحقق منه في كل طلب (تعطيل الحساب بيسري فوراً).
- الصلاحيات: `admin` / `coach` / `student`. المدرب يشوف بس الطلاب المسجلين في كلاساته. ملاحظات المدرب مخفية عن الطالب.
- Rate limit على تسجيل الدخول، `helmet`، حد لحجم الـ JSON، والـ validation على كل الـ inputs.
- Audit log لكل عملية تعديل (`/api/admin/audit`) وسجل طلبات في الـ console.
- قابلية التوسع: الـ API stateless (التوكن موقّع)، والقوائم فيها pagination. SQLite مناسبة لأكاديمية واحدة؛ لو الحجم كبر، الـ schema قابل للنقل لـ PostgreSQL.

## ملاحظات

- `server/src/access.js` فيه قواعد الملكية (ownership) لكل الـ routes؛ أي صلاحية جديدة تتضاف هناك.
- الـ migration بسيطة الآن (`CREATE TABLE IF NOT EXISTS`)؛ أول تغيير كبير في الـ schema يستاهل نظام migrations.
